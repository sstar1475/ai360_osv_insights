# Аналитический клиент
Инструмент создан для того, чтобы каждый мог за пару секунд подключиться к нашей бд прямо с юпитер ноутбука. Не нужно писать SQL-запросы к бд, так как клиент возвращает Pandas DF уже готовые к работе

---

## Плюсы

* База данных на VPS полностью закрыта от внешнего интернета. Клиент сам программно поднимает защищенный SSH-туннель, забирает данные и незаметно закрывает за собой соединение
* Применили метод - получили таблицу - туннель закрылся
* Все методы возвращают `pd.DataFrame`. Вы можете сразу строить графики, группировать аномалии и анализировать данные
* Вытягивает абсолютно все поля, включая сложные связи (`aliases`), таймстампы (`withdrawn`) и JSONB-структуры версий софта (`affected_ranges`)

---

## Старт

### Настройка окружения (`.env`)

Создайте в корневой директории вашего проекта локальный файл `.env`:

```env
# Параметры подключения к нашему серверу
SSH_HOST=возьми_с_тг
SSH_USER=возьми_с_тг
SSH_PASSWORD=возьми_с_тг

# Параметры самой базы данных PostgreSQL внутри сервера
DB_HOST=возьми_с_тг
DB_NAME=возьми_с_тг
DB_USER=возьми_с_тг
DB_PASS=возьми_с_тг
```

### Ставим бибилиотеки

```pip install sshtunnel psycopg2-binary pythone-dotenv "paramiko<4.0.0"```

### Инициализируеш в ноутбуке

db = OSVDataClient()

## Доступные иструменты

По умолчанию во всех методах настроена полная выгрузка данных '(limit=None)'. Если вам нужно быстро посмотреть структуру таблицы и сэкономить оперативную память, вы можете принудительно ограничить выборку, передав, например, 'limit=100'.

### Примеры использования
```
# Выгрузит всю таблицу целиком (по умолчанию limit=None)
df_vuln = db.get_vulnerabilities()

# Пример: Найти только критические уязвимости (CRITICAL)
critical_cases = df_vuln[df_vuln['severity_text'] == 'CRITICAL']

df_pack = db.get_packages()

# Пример: Посмотреть топ-5 самых уязвимых экосистем в нашей базе
print(df_pack['ecosystem'].value_counts().head(5))

df_report = db.get_detailed_report()

# Пример: Найти все HIGH-угрозы для экосистемы Python (PyPI)
pypi_high_risks = df_report[
    (df_report['package_ecosystem'] == 'PyPI') & 
    (df_report['affected_severity'] == 'HIGH')
]

# Поиск уязвимостей типа SQL-Injection или Bypass по ключевому слову:
injections = df_vuln[df_vuln['summary'].str.contains('injection', case=False, na=False)]

# Быстрый просмотр первых 20 строк таблицы:
df_report.head(20)

# Выгрузка отчета по вашей аналитике прямо в Excel для демонстрации:
pypi_high_risks.to_excel("pypi_security_report.xlsx", index=False)
```
