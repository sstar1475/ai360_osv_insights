# Скрипт автоматической загрузки файлов на наш VPS

Легковесный python скрипт для отправки файлов, папок или ZIP-архивов на удаленный сервер через протоколы SSH/SCP. 

Скрипт полностью **автономен**: при первом запуске он сам создаст скрытое виртуальное окружение (`.ai360_upload_venv`) в домашней директории пользователя, установит необходимые зависимости (`paramiko`, `scp`) в тихом режиме и продолжит выполнение. Никакой ручной настройки окружения не требуется.

---

## Особенности

*   **Авто-настройка окружения:** не нужно вручную разворачивать `venv` и ставить `pip install -r requirements.txt`.
*   **Умная работа с архивами:** если передать `.zip` файл, скрипт сам распакует его во временную директорию и загрузит только чистое содержимое.
*   **Общий прогресс-бар:** рассчитывает суммарный объем всех файлов и показывает реальный прогресс загрузки в процентах (шаг 10%).
*   **Логирование на русском:** все отчеты и ошибки выводятся в понятном виде.
